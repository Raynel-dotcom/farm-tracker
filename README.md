# Farm & Rental Tracker

This is the Farm & Rental Tracker for dadi, tracking rental income, matooke sales, coffee sales, and farm/rental expenses, backed by Supabase. Please see [docs/README-dadi.md](docs/README-dadi.md) for a plain-language guide on how to use the application, and [docs/architecture-farm.md](docs/architecture-farm.md) for detailed technical specifications and the system design.
